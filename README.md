### Интеграции

#### Last.fm

Если не включены другие (Spotify, Apple Music, Yandex Music, etc.), то Last.fm будет использоваться для получения статуса текущего проигрываемого трека, в противном случае текущий трек берётся из выбранной интеграции в Discord.

Если включается интеграция Last.fm, то интеграции с другими проигрывателями будут недоступны.

Вариант а)

- Логин аккаунта
- API-ключ (<https://www.last.fm/api/accounts>, для создания <https://www.last.fm/api/account/create>)

Вариант б)

- Кнопка с логином через OAuth (не знаю как с ним работать однако, но не думаю что проблемно)

- (Возможно,) интерактивная плашка с текущим треком (если включена интеграция)
- Слайдер с количеством % для скроббла

### Музыккальные приложения

Всё ещё не очень понятно, как получать текущий трек из приложения в зависимости от платформы
Для Apple Music подойдёт UIA (только Windows (и, возможно, Linux)) - нужен C#
Возможно, можно подключаться по IPC

*Важно*: Из-за приколов Last.fm API выходит кидать запрос только раз в 30 секунд. С интеграцией из музыкальных приложений можно ускорить частоту обновления для Discord.

Если же идёт скробблинг, по идее можно кидать запрос на проигрываемый трек при смене трека и скробблить на определнном проценте.

#### Spotify

- Тогглер для использования интеграции (не работает при включённой интеграции last.fm)
- Тогглер для скроббилинга (нужен настроенный last.fm)

Под спойлером:

- Spotify App Client ID (для получения обложек)
- Spotify App Client Secret (для получения обложек)

#### Apple Music

- Тогглер для использования интеграции (не работает при включённой интеграции last.fm)
- Тогглер для скроббилинга (нужен настроенный last.fm)
